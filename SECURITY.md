# Reporting a private-data issue

If you find a credential, personal vehicle identifier or private server address in this portfolio repository, please do not repeat the value in a public issue. Use GitHub's private vulnerability reporting for this repository when available.

For ordinary code or UI bugs, a public issue is fine. Use demo data and omit account details, VINs, server URLs, log files and personal screenshots.

This personal project is not an official Opel application or a supported vehicle-control product.
